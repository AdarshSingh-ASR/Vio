## 📱 Screenshot Specifications

### **Technical Requirements**
- **Resolution**: 1920x1080 (Full HD) minimum
- **Format**: PNG or high-quality JPEG
- **File size**: Under 5MB per image
- **Aspect ratio**: 16:9 for consistency

### **Visual Quality**
- **Clean interface**: Remove personal information, bookmarks, notifications
- **Consistent theme**: Use the same theme/color scheme throughout
- **Clear text**: Ensure all text is readable and crisp
- **Professional appearance**: Clean, modern, and polished look

### **Content Guidelines**
- **Use sample data**: Avoid real personal information
- **Show variety**: Demonstrate different content types and features
- **Highlight key features**: Focus on innovative and impactful features
- **Tell a story**: Screenshots should show a logical user journey
